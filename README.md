# Mówię — польский с нуля до A2

Курс польского языка для русскоязычных: 46 уроков (A1–A2) в стиле учебника, грамматический справочник и словарь на 1000+ слов с интервальным повторением.

Сайт: см. раздел **Settings → Pages** этого репозитория.

## Как устроен проект

- `src/app.html` — движок приложения (интерфейс, задания, тренажёр слов).
- `src/data/*.js` — уроки (`a1_*`, `a2_*`), словарь (`w*`), задания в стиле учебника (`z_book.js`), грамматические термины и справочник (`z_gram.js`).
- `build.py` — собирает всё в один файл: `mowie.html` и сайт `docs/index.html`.
- `brand/` — логотип и обложка.

## Сборка

```
python build.py
```

После сборки закоммитьте и отправьте изменения — GitHub Pages обновит сайт автоматически.

## Публикация

Дважды щёлкните `publish.bat`: он соберёт курс, сохранит изменения и отправит их на GitHub. Через 1–2 минуты сайт https://ray91333.github.io/mowie/ обновится сам.
